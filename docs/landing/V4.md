# Landing page v4

Branch `landing-v4`. Structure and visual language follow the Dribbble shot chosen by the project owner, "Zenith — AI Ops Automation Landing Page" by Elux Space. It was analysed on 2026-10-13 in the owner's browser, and 24 frames were extracted from its 21.75 s video. None of the shot's images, text or code are in the repository.

## Section mapping

| Zenith | Spokemark |
|---|---|
| Hero: badge, two-line centred headline, grey subheadline, white pill CTA with an arrow disc, glowing iridescent hills with a sweeping flare | Same layout. The hills are **sound waves**: a WebGL shader (`js/waves.js`) draws 14 waveform ridges with fibres, glitter, crest highlights and a warm flare. Their ripple follows the speech and pause steps of the real `jfk.wav` log. |
| "Chosen by…" metric carousel, green up-arrow dots | Six measured results from `RESULTS.md` (no customer claims) |
| "How it works" tabs with a pause button over a dark app window on a wave background | Capture / Detect / Recognize / Confirm tabs that follow the live replay; the window mock shows the on-device pipeline steps and the real transcript |
| "Why Zenith?" list with one open item, plus a TRIGGER/ACTION workflow card | "Why Spokemark?" features, plus a TRIGGER/STEP/OUTPUT card for the caption pipeline |
| "vs Alternatives" three cards with coloured letter tiles | "Built in the open": MIT, measured results, build from source (no competitors named) |
| Integrations grid and security pills | Apps the README lists, plus nine privacy facts; untested calls are stated |
| "An entire IT team in an agent" 2×2 grid | "A caption engine in your menu bar" 2×2 grid |
| "Ready to scale?" with a form | "Ready to read along?": the requirements, styled as the form's pill fields, and the download button. No form, because the page collects no data. |
| Footer with columns and socials | Same pattern, with project links |

**Palette:** the shot's own. Near-black `#080808`, cards `#111112`, ember `#F2541B` (`#C2410C` behind white text), green `#22C55E` and cobalt `#3B6CF6`.

**Type:** Manrope (OFL, 400–700, a 21 KB subset), the same geometric grotesk family.

## Verification (2026-10-13)

- **Screenshots:** `screenshots/v4/final-{390,768,1440,1920}.webp`. No horizontal scroll at any width.
- **Lighthouse mobile** (Pages-like local server, 2 runs): Performance 100, Accessibility 100, Best Practices 100, SEO 100; LCP 1.2 s (the subheadline), CLS 0, TBT 20 ms.
- **Waves:** 60 fps on the M4. They pause outside the viewport and in hidden tabs, and with the Pause control (WCAG 2.2.2). With reduced motion, software WebGL or under 45 fps they become still frames.
- **Accessibility:** one `h1`. All old anchors resolve. Keyboard order is logical. The tablist contains only tabs.
